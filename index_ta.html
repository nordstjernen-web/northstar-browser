Nordstjernen வலை உலாவி

Nordstjernen என்பது C இல் முதலில் இருந்து எழுதப்பட்ட ஒரு வலை உலாவி, இது HTML மற்றும் CSS தரநிலைகளை ஆதரிப்பதில் கவனம் செலுத்துகிறது. இது Windows, Mac மற்றும் Linux இல் இயங்குகிறது, Android போர்ட் முன்னேற்றத்தில் உள்ளது. Nordstjernen நார்வேயில் உருவாக்கப்பட்டது.

Nordstjernen ஒரு பக்கத்தை வழங்குகிறது. மேலும் திரைப்பிடிப்புகள் »

HTML தரநிலை. நடத்தை மற்றொரு உலாவியுடன் ஒப்பிடாமல், பிரிவு வாரியாக தரநிலை உரையுடன் ஒப்பிட்டு அளவிடப்படுகிறது.

பாதுகாப்பானது. தாவலுக்கு ஒரு செயல்முறை வடிவமைப்பு — ஒவ்வொரு தாவலும் அதன் சொந்த சாண்ட்பாக்ஸ் செய்யப்பட்ட ரெண்டரர் செயல்முறையில் இயங்குகிறது (Linux இல் seccomp + Landlock), IPC மற்றும் பகிரப்பட்ட-நினைவக ஃப்ரேம்பஃபர்கள் வழியாக UI உடன் தொடர்பு கொள்கிறது. JIT இல்லை.

குறைந்தபட்சவாதம். முழு இயந்திரமும் C இன் ஒரு சிறிய தொகுப்பு — ஒரு நபர் தொடக்கத்திலிருந்து முடிவு வரை படித்து தணிக்கை செய்யும் அளவுக்கு சிறியது.

Nordstjernen இல் JIT இல்லை, எனவே இது மிகவும் பாதுகாப்பானது, இன்னும் போதுமான அளவு வேகமாக இருக்க முடியும். இது எந்த வகையான டெலிமெட்ரியையும் அனுப்புவதில்லை.
