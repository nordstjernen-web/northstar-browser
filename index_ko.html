Nordstjernen 웹 브라우저

Nordstjernen은 C로 처음부터 작성된 웹 브라우저로, HTML 및 CSS 표준 지원에 중점을 두고 있습니다. Windows, Mac, Linux에서 실행되며 Android 포팅도 진행 중입니다. Nordstjernen은 노르웨이에서 만들어졌습니다.

Nordstjernen이 페이지를 렌더링하는 모습. 스크린샷 더 보기 »

HTML 표준. 동작은 다른 브라우저가 아니라 명세 텍스트를 기준으로 절마다 측정됩니다.

보안. 탭별 프로세스 설계 — 각 탭은 자체 샌드박스 렌더러 프로세스(Linux에서는 seccomp + Landlock)에서 실행되며, IPC와 공유 메모리 프레임버퍼를 통해 UI와 통신합니다. JIT 없음.

미니멀리즘. 엔진 전체가 간결한 C 코드 덩어리이며 — 한 사람이 처음부터 끝까지 읽고 감사할 수 있을 만큼 작습니다.

Nordstjernen은 JIT가 없어 훨씬 더 안전하며, 그러면서도 충분히 빠를 수 있습니다. 어떤 종류의 텔레메트리도 포함하지 않습니다.
