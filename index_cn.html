Nordstjernen 网页浏览器

Nordstjernen 是一款用 C 语言从零编写的网页浏览器，专注于支持 HTML 和 CSS 标准。它可在 Windows、Mac 和 Linux 上运行，Android 版本正在开发中。Nordstjernen 在挪威打造。

Nordstjernen 正在渲染页面。更多截图 »

HTML 标准。 行为以规范文本为准逐节衡量，而不是以另一款浏览器为参照。

安全。 每标签页独立进程的设计 — 每个标签页运行在自己的沙箱渲染进程中（在 Linux 上为 seccomp + Landlock），通过 IPC 和共享内存帧缓冲与界面通信。无 JIT。

极简主义。 整个引擎是一段紧凑的 C 代码 — 小到一个人就能从头到尾阅读和审计。

Nordstjernen 没有 JIT，因此安全得多，并且仍然足够快。它不附带任何形式的遥测。
