నార్డ్‌స్టర్నెన్ వెబ్ బ్రౌజర్

నార్డ్‌స్టర్నెన్ అనేది C లో మొదటి నుండి వ్రాయబడిన ఒక వెబ్ బ్రౌజర్, ఇది HTML మరియు CSS ప్రమాణాలకు మద్దతు ఇవ్వడంపై దృష్టి సారిస్తుంది. ఇది Windows, Mac మరియు Linux లపై నడుస్తుంది, Android పోర్ట్ ప్రగతిలో ఉంది. నార్డ్‌స్టర్నెన్ నార్వేలో నిర్మించబడింది.

నార్డ్‌స్టర్నెన్ ఒక పేజీని రెండర్ చేస్తోంది. మరిన్ని స్క్రీన్‌షాట్‌లు »

HTML ప్రమాణం. ప్రవర్తన మరొక బ్రౌజర్‌తో కాకుండా, విభాగం వారీగా స్పెసిఫికేషన్ టెక్స్ట్‌తో పోల్చి కొలవబడుతుంది.

సురక్షితమైనది. ప్రతి-ట్యాబ్-కు-ఒక-ప్రాసెస్ రూపకల్పన — ప్రతి ట్యాబ్ దాని స్వంత శాండ్‌బాక్స్ చేయబడిన రెండరర్ ప్రాసెస్‌లో నడుస్తుంది (Linux లో seccomp + Landlock), IPC మరియు షేర్డ్-మెమరీ ఫ్రేమ్‌బఫర్‌ల ద్వారా UI తో మాట్లాడుతుంది. JIT లేదు.

కనిష్టత్వం. మొత్తం ఇంజిన్ ఒక సంక్షిప్త C కోడ్ సమూహం — ఒక వ్యక్తి మొదటి నుండి చివరి వరకు చదివి ఆడిట్ చేయడానికి తగినంత చిన్నది.

నార్డ్‌స్టర్నెన్‌కు JIT లేదు, కాబట్టి ఇది చాలా సురక్షితమైనది, అయినా తగినంత వేగంగా ఉంటుంది. ఇది ఎలాంటి టెలిమెట్రీని పంపదు.
