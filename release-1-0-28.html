Nordstjernen Browser 1.0.28 released!

Today, 4 October 2026, we are pleased to announce the release of Nordstjernen 1.0.28. The headline is the license: Nordstjernen is now dual-licensed, and may be used, modified and redistributed under either the GNU General Public License, version 3 or later, or the Nordstjernen Source License 1.0, at the recipient’s option. Around it, 1.0.28 gives the browser window and the built-in pages a new look, runs Google’s search pages, and makes style resolution, script parsing and container-query layout markedly faster. Nordstjernen is a web browser, written from scratch in C, focused on supporting the HTML and CSS standards. It runs on Windows, macOS and Linux, with builds for Android, iOS, FreeBSD, NetBSD and the JVM. Nordstjernen is built in Norway.

Nordstjernen Browser version 1.0.28 is available now, with a portable Linux zip and a Debian/Ubuntu package. Read the full release notes here, or jump straight to the downloads. This page also covers 1.0.25, 1.0.26 and 1.0.27, released in the weeks since 1.0.24.

It ships alongside Northstar 1.0.12, the minimalist GPL edition of the same engine.

what’s new in 1.0.28

  • GPL 3 or NSL, your choice. Nordstjernen is dual-licensed under LicenseRef-NSL-1.0 OR GPL-3.0-or-later. A recipient who takes the GPL option receives the browser under the GPL alone. The GPL text ships as COPYING in every package and shows at about:gpl; the About page and the Debian, RPM, openSUSE, Alpine, Maven and AppStream metadata declare both licenses.
  • A new window. The browser window has a flatter look that follows the light or dark desktop theme, and the built-in pages share one modern style with light and dark colours. Switching tabs updates the tab strip, the address bar and the window title together.
  • Google’s pages run. Frames are their own JavaScript realms, timers are no longer lost, and the engine’s interfaces have the shapes other browsers give them — instanceof follows the prototype chain, the canvas, WebGL, IndexedDB, MediaSource, Cache and Observable interfaces are real. Content too wide for a centred line starts at the line’s start, which puts reCAPTCHA’s image tiles where they belong.
  • Faster. Whether an attribute selector compares case-insensitively is decided once per selector, not once per element: Speedometer’s Complex-DOM suites run about 18% faster. Scripts with many functions parse about 9% faster, a <form> caches its control list (three times faster on a form with a hundred controls), and pages with container queries relayout in one pass instead of two when no container changed size — Google’s results page ran the second pass on 44 of its 45 relayouts.
  • Correctness. Constructed style sheets adopted by a shadow root style it again, a style sheet styles only its own document, a page with many shadow roots no longer crashes the renderer, prepend() with the parent’s first child no longer hangs, a box that sizes itself to its content counts calc() widths, and YouTube playback gets a faster restyle and no stale stream after ads.
  • Fetch. Empty POSTs, request body types and redirect rules follow the Fetch standard, XMLHttpRequest sends the Content-Type its body calls for, and SharedArrayBuffer is only on the global object of cross-origin-isolated pages.

since 1.0.24

  • 1.0.27 (2 October) — DuckDuckGo is the default search engine; the desktop browser records visited pages in History; every published release gets a Debian/Ubuntu .deb and a portable Linux zip; deeply nested CSS values, SVGs and documents no longer crash the renderer; frames, workers and message ports follow the HTML event and document-lifecycle model; Nordstjernen can be built on Fabrice Bellard’s original QuickJS as well as quickjs-ng; lexbor is refreshed; and YouTube and other MSE players play video again.
  • 1.0.26 (26 September) — grids with more than 24 rows and with grid-template-areas lay out fully; popovers and <dialog> follow the HTML show and close steps; :focus-visible and autofocus work; the default stylesheet follows the HTML rendering section; styling a large page is much faster; and a round of security fixes — the audio helper opens only what a page may play, the Windows process mitigations are the ones intended, and a page can no longer read the pixels of another site’s images or script a cross-origin frame.
  • 1.0.25 (20 September) — restyling a large document is about 40% faster; the toolbar and about:start take the classic look of the Northstar browser; container queries evaluate the full condition grammar; transitions and animations run on every property, with the Web Animations API; the background and border shorthands parse per the grammar; position: fixed stays anchored while the page scrolls; and quickjs-ng moves to 0.16.2.

about Nordstjernen

HTML Standard. Behaviour is measured against the spec text, section by section, not against another browser — 140 spec rows fully implemented, 31 partial, 0 absent across WHATWG HTML sections 1–16. See docs/HTML-compatibility.md.

Secure. Process-per-tab design — each tab's engine runs in its own sandboxed process (seccomp + Landlock on Linux), talking to the UI over IPC and shared-memory framebuffers · no JIT.

Minimalism. The core engine is about 210,000 lines of project C and headers, excluding the vendored libraries and generated assets — small enough for one person to read and audit end-to-end.

Private. Nordstjernen ships no telemetry of any kind, and deliberately includes no AI assistant and no AI-style web APIs.
