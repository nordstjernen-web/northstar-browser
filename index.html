nordstjernen

An independent web browser written in C. Around 40,000 lines, small enough for one person to read in a long afternoon. No Blink, no Gecko, no WebKit, no JIT. No telemetry, ever.

Nordstjernen 0.6.0 on Linux / GTK 4.
