Welcome to nordstjernen.org.

Nordstjernen is an independent web browser written in C, by Andreas Røsdal. Source-available, no telemetry, no JIT.

A north star, small and faithful — light enough to read by, slow enough to think with; built one line at a time.

Nordstjernen is a web browser for people who want to read the web — Wikipedia, news, documentation, search results, light forms — without donating a few hundred million lines of someone else's engine and a few hundred kilobytes of telemetry to the experience. It is around 40,000 lines of C, small enough that a single human can read the whole thing in a long afternoon. It uses GTK 4 for the user interface and libcurl for networking; the HTML / CSS parsers, layout, paint, and JavaScript bindings are written from scratch — no Blink, no Gecko, no WebKit, no JIT.

what you get

Auditability. One person can read the entire engine. Clean-room implementation — not Blink, not Gecko, not WebKit.

Privacy by construction. No telemetry, no update pinger, no crash reporter, no "studies". DuckDuckGo Lite as default search. Cache and connections partitioned per top-level site.

Smaller attack surface. No WebGL, no WebGPU, no WebRTC, no service workers, no MSE, no DRM, no extensions, no plugins. JavaScript runs on QuickJS — an interpreter, no JIT, W^X process-wide.

Conservative network defaults. TLS verification on, HTTP/HTTPS only, built-in HSTS preload list, max 10 redirects per request, 60s per HTTP request, 60s per JS execution slice.

security model

On Linux the renderer runs under a Landlock sandbox that removes read access to ~/.ssh, ~/.gnupg, other browsers' profiles, and arbitrary dotfiles. The browser refuses to run as root on Linux / macOS or as Administrator on Windows.

The binary is compiled with PIE, full RELRO, stack-protector-strong, stack-clash protection, Intel CET, _FORTIFY_SOURCE=2, and a no-exec stack.

This is not a Chromium-grade adversary-resistant browser and it does not pretend to be. The threat model is sloppy or mildly hostile websites running on top of a trusted operating-system user, and the design is kept small enough to defend honestly.
