The small, steady web browser.

v0.6.0  released 18 May 2026
"A north star, small and faithful — light enough to read by,
slow enough to think with; built one line at a time."

Download »   View Source

Nordstjernen is a web browser for people who want to read the web — Wikipedia, news, documentation, search results, light forms — without donating a few hundred million lines of someone else's engine and a few hundred kilobytes of telemetry to the experience.

It is around 40,000 lines of C, small enough that a single human can read the whole thing in a long afternoon. It uses GTK 4 for the user interface and libcurl for networking; the HTML / CSS parsers, layout, paint, and JavaScript bindings are written from scratch — no Blink, no Gecko, no WebKit, no JIT.

★ What you get

Auditability

  • One person can read the engine end-to-end.
  • ~40,000 lines of C, no hidden vendoring.
  • Clean-room: no Blink, Gecko, or WebKit.

Privacy by construction

  • No telemetry, ever. No phone-home.
  • No update pinger, no crash reporter, no "studies".
  • DuckDuckGo Lite as default search.
  • Cache & connections partitioned per top-level site.
  • Third-party cookies off by default.

Smaller attack surface

  • No WebGL, no WebGPU, no WebRTC.
  • No service workers, no MSE, no DRM.
  • No extensions, no plugins.
  • JavaScript via QuickJS — an interpreter, no JIT, W^X process-wide.

Conservative network

  • TLS verification on; HTTP/HTTPS only.
  • Built-in HSTS preload list.
  • Max 10 redirects, 60s per request, 60s per JS slice.
  • gzip / brotli / zstd via libcurl.

★ Hardening & sandbox

On Linux the renderer runs under a Landlock sandbox that removes read access to ~/.ssh, ~/.gnupg, other browsers' profiles, and arbitrary dotfiles; only the nordstjernen-specific subdirs under $XDG_*_HOME are writable. The browser refuses to run as root on Linux / macOS or as Administrator on Windows.

The binary is compiled with PIE, full RELRO, stack-protector-strong, stack-clash protection, Intel CET, _FORTIFY_SOURCE=2, and a no-exec stack.

Note. This is not a Chromium-grade adversary-resistant browser and it does not pretend to be. The threat model is sloppy or mildly hostile websites running on top of a trusted operating-system user, and the design is kept small enough to defend honestly.
