Nordstjernen

The small, steady web browser.

Version 0.6.0 · written in C · by Andreas Røsdal

Nordstjernen is a web browser for people who want to read the web without donating a few hundred million lines of someone else's engine and a few hundred kilobytes of telemetry to the experience.

It is around 40,000 lines of C — small enough that a single human can read the whole thing in a long afternoon. No Blink, no Gecko, no WebKit, no JIT.
