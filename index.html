[ THE NORTH STAR ]

What is Nordstjernen?

A north star, small and faithful — light enough to read by,
slow enough to think with; built one line at a time.

Nordstjernen is a web browser for people who want to read the web — Wikipedia, news, documentation, search results, light forms — without donating a few hundred million lines of someone else's engine and a few hundred kilobytes of telemetry to the experience. It is around 40,000 lines of C, small enough that a single human can read the whole thing in a long afternoon. It uses GTK 4 for the user interface and libcurl for networking; the HTML / CSS parsers, layout, paint, and JavaScript bindings are written from scratch — there is no Blink, no Gecko, no WebKit, no JIT.

★ What you get

In return for the smaller feature set:

  • Auditability — one person can read the entire engine.
  • Privacy by construction — no telemetry, no update pinger, no crash reporter, no "studies". DuckDuckGo Lite is the default search.
  • Smaller attack surface — no WebGL, no WebGPU, no service workers, no MSE, no extensions, no plugins, no DRM.
  • No JIT — JavaScript runs on QuickJS, an interpreter. The most prolific category of in-the-wild browser RCEs (V8 / SpiderMonkey JIT bugs) is foreclosed entirely.
  • Conservative network defaults — TLS verification on, HTTP/HTTPS only, built-in HSTS preload list, max 10 redirects per request, 60s per HTTP request, 60s per JS slice.
  • Partitioned cache & connections — the same CDN URL cannot track you across sites via cache timing.
  • Landlock sandbox on Linux — removes read access to ~/.ssh, ~/.gnupg, other browsers' profiles, and arbitrary dotfiles.
  • Hardened binary — PIE, full RELRO, stack-protector-strong, stack-clash protection, Intel CET, _FORTIFY_SOURCE=2, no-exec stack.
  • Refuses to run as root on Linux / macOS or as Administrator on Windows.

This is not a Chromium-grade adversary-resistant browser and it does not pretend to be. It will not match Chrome or Firefox feature-for-feature; the threat model is sloppy or mildly hostile websites running on top of a trusted operating-system user, and the design is kept small enough to defend honestly.

Deliberately excluded

  • WebGL, WebGPU
  • WebRTC
  • Service workers, MSE
  • DRM (EME)
  • Extensions and plugins
  • Persistent history
  • Sync, accounts
  • JIT compilation

A browser is a tool. Smaller surface, fewer surprises.
