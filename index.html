What it is

Independent engine

~40,000 lines of C. Not Blink, not WebKit, not Gecko. A clean-room implementation.

No telemetry, ever

No phone-home, no update pinger, no Safe Browsing. The browser does not talk about you.

No JIT

JavaScript runs on QuickJS, an interpreter. W^X holds process-wide. A smaller attack surface.

Sandboxed

Landlock + seccomp, PIE, full RELRO, stack protector. Defence in depth, by default.

Modern enough

HTML5 via lexbor. Flexbox, grid, custom properties, animations, sticky positioning. WebP, AVIF, SVG, WebM/VP9.

Any script

Latin, Arabic, CJK — anything with a system font. RTL via FriBidi and HarfBuzz.
