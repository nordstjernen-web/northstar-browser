Welcome to Nordstjernen.

"A north star, small and faithful — light enough to read by,
slow enough to think with; built one line at a time."

Nordstjernen is a web browser for people who want to read the web — Wikipedia, news, documentation, search results, light forms — without donating a few hundred million lines of someone else's engine and a few hundred kilobytes of telemetry to the experience.

It is around 40,000 lines of C, small enough that a single human can read the whole thing in a long afternoon. It uses GTK 4 for the user interface and libcurl for networking; the HTML / CSS parsers, layout, paint, and JavaScript bindings are written from scratch — no Blink, no Gecko, no WebKit, no JIT.

★ WHAT'S COOL
No telemetry, ever. No phone-home, no update pinger, no crash reporter, no "studies". DuckDuckGo Lite is the default search.
No JIT. JavaScript runs on QuickJS — an interpreter. The most prolific category of in-the-wild browser RCEs (V8/SpiderMonkey JIT bugs) is foreclosed entirely.
Smaller attack surface. No WebGL, no WebGPU, no WebRTC, no service workers, no MSE, no DRM, no extensions, no plugins.
★ SECURITY MODEL
On Linux the renderer runs under a Landlock sandbox that removes read access to ~/.ssh, ~/.gnupg, and other browsers' profiles. The binary is compiled with PIE, full RELRO, stack-protector-strong, stack-clash protection, Intel CET, _FORTIFY_SOURCE=2, and a no-exec stack. Refuses to run as root.
Network defaults: TLS verification on, HTTP/HTTPS only, built-in HSTS preload list, max 10 redirects, 60s per request, 60s per JS slice. Cache and connections partitioned per top-level site.
