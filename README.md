# nordstjernen.org

The user-facing home for **Nordstjernen** — a clean-room web browser
written from scratch in C, with a GTK 4 UI, designed to stay small,
secure, and readable by a single human.

This repository is the community hub for the project. The browser's
source code lives in a separate repository.

- **Project website:** https://nordstjernen.org
- **Browser source code:** https://github.com/operativsystem42/nordstjernen

## About the browser

Nordstjernen runs on Linux, macOS, and Windows, and supports HTML5,
modern CSS, and a pragmatic subset of modern JavaScript. It is secure
by default (TLS verification, dynamic HSTS, CSP, SOP/CORS, per-window
process separation, Linux Landlock sandbox) and ships with no
telemetry, no plugins, and no extensions.

Distribution model: **shareware**, in the spirit of early Opera. Free
to download and try; a polite nag eventually asks for a license. The
binary keeps working either way.

For the full feature list and development plan, see the
[browser repository](https://github.com/operativsystem42/nordstjernen).
