# Contributing to Nordstjernen

Thanks for your interest in Nordstjernen! This repository
(`nordstjernen.org`) is the community-facing hub for the project. The
browser's source code lives at
[operativsystem42/nordstjernen](https://github.com/operativsystem42/nordstjernen).

## Where to file what

- **Bug in the browser** (crash, wrong rendering, broken site,
  security issue) → open an
  [issue here](https://github.com/operativsystem42/nordstjernen.org/issues).
- **Question or idea** → start a
  [discussion](https://github.com/operativsystem42/nordstjernen.org/discussions).
- **Documentation, tips, FAQs** → contribute to the
  [wiki](https://github.com/operativsystem42/nordstjernen.org/wiki).
- **Pull request against the browser code** → open it in the
  [browser repository](https://github.com/operativsystem42/nordstjernen),
  not here.

## Filing a good bug report

Please include:

1. **Nordstjernen version** — run `nordstjernen --version`.
2. **Operating system and version** — e.g. "Windows 11 24H2",
   "Ubuntu 24.04", "macOS 15.2".
3. **A reproducible test case** — ideally a URL that shows the
   problem, or a minimal HTML snippet.
4. **What you expected to happen** vs. **what actually happened**.
5. **Steps to reproduce**, if not obvious.
6. **Screenshots** for rendering bugs, if helpful.

For crashes, include the terminal output if you launched the browser
from a shell.

## Security issues

If you believe you've found a security vulnerability, please **do not**
open a public issue. Email the maintainer privately first so the bug
can be triaged before disclosure.

## Code of conduct

Be kind, be precise, and assume good faith. The project is small and
maintained by a single person — patience and clear bug reports go a
long way.
