Nordstjernen Browser 1.0.29 released!

On 5 October 2026 we released Nordstjernen 1.0.29. Pages are now drawn at the screen’s real pixel density, so text and images are sharp on Retina and other HiDPI displays, and scrolling is smooth: the window keeps the page as tiles and moves them itself, so a busy script no longer stops the page from moving. Text fields get the clipboard and a right-click menu, signing in to Google reaches Gmail, text flows around floated pictures as in other browsers, and a security audit of the engine, the shell and the helpers closes a long list of memory-safety bugs. Nordstjernen is a web browser, written from scratch in C, focused on supporting the HTML and CSS standards. It runs on Windows, macOS and Linux, with builds for Android, iOS, FreeBSD, NetBSD and the JVM. Nordstjernen is built in Norway.

Nordstjernen Browser version 1.0.29 is available now, with a portable Linux zip and a Debian/Ubuntu package for each of Ubuntu 24.04, Ubuntu 26.04 and Debian 13. Read the full release notes here, or jump straight to the downloads. The previous release was 1.0.28.

what’s new in 1.0.29

  • Sharp on HiDPI screens. The page is rendered at the window’s scale factor — 2x on a Retina Mac, fractional scales on Linux — and shown pixel for pixel, re-rendering when the window moves to a screen with another scale. devicePixelRatio, the resolution media queries and srcset report the real ratio, so pages pick their sharp images, and windows wider than 2560 CSS pixels are no longer cut off.
  • Smooth scrolling. The renderer paints the page as tiles, with position: fixed and sticky parts in layers of their own, and the window moves the tiles itself. Touchpad scrolling is 1:1 with momentum, and the wheel and the keyboard glide to their target. On a 2x, 120 Hz screen Wikipedia scrolls at 102 frames a second instead of 56, GitHub at 102 instead of 51 and BBC News at 100 instead of 42.
  • Clipboard in text fields. Paste with Ctrl+V, Shift+Insert or Cmd+V, or from a new right-click menu with Cut, Copy, Paste and Select All on inputs, textareas and editable content. Pasting fires a cancelable paste event, honours readonly and maxlength, and password fields cannot be copied or cut.
  • Google sign-in and Gmail. Node methods and attributes check that they are called on a real node, as WebIDL requires, and Google’s sign-in page no longer turns the browser away with “This browser or app may not be secure”: Gmail opens after the email and password steps.
  • Layout like other browsers. Text flows around floats line by line — Wikipedia articles were about 50% taller than in Chrome — margins collapse as in other browsers, paint order follows stacking contexts, zoom reflows the page, wrapping flex containers honour auto margins, Lit components re-render, and fixes land for layouts on Google’s image results, MDN, GitHub, Stack Overflow and apple.com.
  • Fonts. On macOS text uses the same fonts and widths as Chrome — Helvetica, Times, Menlo and San Francisco — measured to a tenth of a pixel. A new in-tree WOFF2 decoder loads web fonts where FreeType was built without Brotli, variable fonts render at the requested weight, and icon fonts used only by ::before and ::after are downloaded.
  • Security audit. Out-of-bounds reads and writes, use-after-free bugs reachable from page script, stack exhaustion from deep nesting and runaway sizes are fixed across the engine; fetch() takes the requesting document from the engine rather than a forgeable location; the shell trusts the sandboxed renderer less; Landlock also restricts symlinks, fifos, sockets and device nodes, and seccomp refuses the terminal-injection ioctls.
  • Faster. The Speedometer 3.1 score rose from 2.40 to 4.70: restyles after a DOM change no longer touch every element that once had a transition, text is measured once per distinct run, repeated <style> elements are matched once, shadow-DOM pages restyle almost four times faster, and large blurred box shadows paint up to 250 times faster. bbc.com/news loads in about 6 s of CPU instead of 33 s.
  • A window that shows its name. “Nordstjernen Browser” sits centred in the title bar, and the Nordstjernen “N” is back at the right end of the toolbar — a click opens nordstjernen.org.
  • One package per distro. The release ships nordstjernen_1.0.29_ubuntu24.04_amd64.deb, …_ubuntu26.04_… and …_debian13_…, each built, installed and started headless on its own release, so it installs on Ubuntu 24.04 and 26.04, where the single 1.0.28 package was refused. Pages load again on macOS versions whose shm_open() rejects O_CLOEXEC. The experimental V8 backend is removed; every build runs on QuickJS.

about Nordstjernen

HTML Standard. Behaviour is measured against the spec text, section by section, not against another browser — 140 spec rows fully implemented, 31 partial, 0 absent across WHATWG HTML sections 1–16. See docs/HTML-compatibility.md.

Secure. Process-per-tab design — each tab's engine runs in its own sandboxed process (seccomp + Landlock on Linux), talking to the UI over IPC and shared-memory framebuffers · no JIT.

Minimalism. The core engine is about 210,000 lines of project C and headers, excluding the vendored libraries and generated assets — small enough for one person to read and audit end-to-end.

Free software. Dual-licensed under the GNU GPL, version 3 or later, or the Nordstjernen Source License 1.0, at your option.

Private. Nordstjernen ships no telemetry of any kind, and deliberately includes no AI assistant and no AI-style web APIs.

The family. Northstar is the minimalist GPL edition of the same engine, and Southstar is the Rust version: it starts from the Nordstjernen codebase and is being ported to Rust module by module.
