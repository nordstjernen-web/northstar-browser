Nordstjernen ویب براؤزر

Nordstjernen ایک ویب براؤزر ہے، جو C میں شروع سے لکھا گیا ہے، جو HTML اور CSS معیارات کی حمایت پر مرکوز ہے۔ یہ Windows، Mac اور Linux پر چلتا ہے، Android پورٹ زیرِ تکمیل ہے۔ Nordstjernen ناروے میں بنایا گیا ہے۔

Nordstjernen ایک صفحہ رینڈر کر رہا ہے۔ مزید اسکرین شاٹس »

HTML معیار۔ رویّے کو کسی دوسرے براؤزر کے بجائے، حصہ بہ حصہ معیاری متن کے مقابلے میں ماپا جاتا ہے۔

محفوظ۔ فی ٹیب ایک پروسیس ڈیزائن — ہر ٹیب اپنے علیحدہ سینڈ باکس شدہ رینڈرر پروسیس میں چلتا ہے (Linux پر seccomp + Landlock)، جو IPC اور شیئرڈ میموری فریم بفرز کے ذریعے UI سے بات کرتا ہے۔ کوئی JIT نہیں۔

کم سے کم پن۔ پورا انجن C کا ایک مختصر مجموعہ ہے — اتنا چھوٹا کہ ایک شخص شروع سے آخر تک پڑھ اور آڈٹ کر سکے۔

Nordstjernen میں کوئی JIT نہیں ہے، اس لیے یہ بہت زیادہ محفوظ ہے، اور پھر بھی کافی تیز ہو سکتا ہے۔ یہ کسی بھی قسم کی ٹیلی میٹری نہیں بھیجتا۔
