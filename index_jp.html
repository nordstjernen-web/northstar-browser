Nordstjernen ウェブブラウザ

Nordstjernen は C 言語でゼロから書かれたウェブブラウザで、HTML および CSS 標準のサポートに重点を置いています。Windows、Mac、Linux で動作し、Android 版も開発中です。Nordstjernen はノルウェーで作られています。

Nordstjernen がページを描画しているところ。その他のスクリーンショット »

HTML 標準。 動作は別のブラウザではなく、仕様書のテキストに照らして節ごとに評価されます。

セキュア。 タブごとにプロセスを分離する設計 — 各タブは独自のサンドボックス化されたレンダラープロセスで実行され（Linux では seccomp + Landlock）、IPC と共有メモリのフレームバッファを通じて UI と通信します。JIT なし。

ミニマリズム。 エンジン全体はコンパクトな C コードの集まりで — 一人で最初から最後まで読んで監査できるほど小さいのです。

Nordstjernen には JIT がないため、はるかに安全であり、それでも十分に高速です。いかなる種類のテレメトリも搭載していません。
